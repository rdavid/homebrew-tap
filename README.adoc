== About

This is a {url-homebrew}[Homebrew] tap with formulae for tools by David
Rabkin.

== Install

Install a formula with:

[,sh]
----
brew install rdavid/tap/<formula>
----

Alternatively, add the tap once and install by name:

[,sh]
----
brew tap rdavid/tap
brew install <formula>
----

== Formulae

[cols="1,3"]
|===
|Formula |Description

|{url-renamr}[renamr]
|File and directory name normalizer.
|===

== Updating

Update the tap and upgrade a formula with:

[,sh]
----
brew update
brew upgrade <formula>
----
