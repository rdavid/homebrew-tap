== About

This is a {url-homebrew}[Homebrew] tap with formulas for tools by David
Rabkin.
ifndef::pages-build[]
The tap also has a {url-pages}[website].
endif::[]

== Install

Install a formula with:

[,sh]
----
brew install rdavid/tap/<formula>
----

Or add the tap once, then install by name:

[,sh]
----
brew tap rdavid/tap
brew install <formula>
----

== Formulas

[cols="1,3"]
|===
|Formula |Description

|{url-renamr}[renamr]
|File and directory name normalizer.
|===

== Update

Update the tap and upgrade a formula with:

[,sh]
----
brew update
brew upgrade <formula>
----
